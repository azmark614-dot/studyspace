# StudySpace

A modern bilingual English / Kurdish Sorani study workspace for GitHub Pages.

## Publish from an Android phone
1. Open https://github.com in Chrome and sign in.
2. Open your repository named `studyspace`.
3. Tap **Add file** → **Upload files**.
4. Upload `index.html` (the actual HTML file, not only the ZIP).
5. Tap **Commit changes**.
6. Open repository **Settings** → **Pages**.
7. Under Build and deployment, choose **Deploy from a branch**.
8. Choose branch `main` and folder `/(root)`, then tap **Save**.
9. Wait a minute or two. Your site address will look like `https://YOUR-USERNAME.github.io/studyspace/`.

## Features
- Modern purple dashboard and responsive mobile layout.
- Unlimited subjects and notes, limited by browser storage.
- Rich text: bold, italic, underline, text highlight, bullet lists and numbered lists.
- Notebook drawing pad with finger or stylus, pen, highlighter, eraser, undo, and clear drawing.
- Question-and-answer cards saved under a subject.
- Flashcards with tap-to-reveal answers.
- Create multiple-choice quizzes with four choices per question.
- Take quizzes, view correct answers, and track quiz scores and best score.
- Search notes, English / Kurdish Sorani interface and right-to-left Kurdish layout.
- Export and import a JSON backup, including study items, quizzes, and quiz attempts.

## Important
Notes and study data are stored in this browser on this device and do not automatically sync to other devices. Export backups regularly. Use the updated `index.html` to publish all features.
